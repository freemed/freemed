help-traversal-prefix.txt — PRE-FIX anonymous exposure of help.php (Task 2.1 evidence, help.php half)

WHY THIS FILE EXISTS
--------------------
Task 2.1's brief asks for the pre-fix exploit transcript. For help.php the
measurable pre-fix fact is not a file read (see "traversal rows" below — no
payload ever returned file contents on this stack) but the ANONYMITY of the
endpoint that the vulnerable path resolver fed: an unauthenticated request served
5818 bytes of help HTML. That is the exposure the Phase 1 fix and its LoggedIn gate
removed, and it is the row an advisory can quote. The relay half of Task 2.1 is in
relay-sqli-prefix.txt.

--- Apache :38081, WITH a valid session -------------------------------------------------------
GET /help.php/gwt/en_US/main   (login-probe session cookie replayed)

So pre-fix the endpoint answered identically with and without a session: there was
no access control at all, and the file it served was chosen by a PATH_INFO-derived
path that only sanitised $ui and $locale, never the page tail (the Phase 1 finding).

NO PAYLOAD RETURNED FILE CONTENTS on either server. Dot segments are consumed by both
servers before PHP runs (400/404), and the shapes that do reach PHP arrive as literal
text that simply fails file_exists() and prints "Help index … not present." This is a
measured negative, not an inference: it matches verify-env.md §6 D-a and it is why the
Phase 1 fix is characterised as closing a real anonymity/validation defect plus a
currently-unreachable traversal path, not an exploited one.

Note the counter in that output: "0 auth required (401/403)". Against the PRE-FIX tree

own summary says the same thing in its closing paragraph: "This is NOT a statement that
help.php is safe: where the server collapses the dot segment upstream the vulnerable
code is never reached."

=============================================================================
C. POST-FIX CONTRAST — measured at HEAD, clearly NOT the pre-fix state
=============================================================================

Same two servers, same URLs, after Phase 1 + this task's change:

  anon   GET /help.php/gwt/en_US/main   →  HTTP/1.1 401 Unauthorized
                                           body: Authentication required.
  authed GET /help.php/gwt/en_US/main   →  HTTP 200, 5818 bytes, unchanged help HTML

That pair is the before/after for the help.php half: 200 + content for anyone before,
401 for an anonymous caller after, 200 + content for an authenticated one after.
